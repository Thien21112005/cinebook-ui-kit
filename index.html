🎯 Mục tiêu & Bài toán Concurrency

CineBook giải quyết bài toán cốt lõi: hàng trăm người cùng tranh 1 ghế trong 1 suất chiếu mà không bị lỗi double-booking, đồng thời tích hợp AI Semantic Search (pgvector) để tìm phim tự nhiên.

🛠️ Stack Công nghệ
  • Frontend: Next.js 15 App Router, Tailwind CSS, TanStack Query, Zustand
  • Backend: NestJS + Go (Goroutine concurrency service)
  • Database & Cache: PostgreSQL + pgvector, Redis (Redlock, TTL seat lock)
  • Queue & Background: RabbitMQ, BullMQ (auto-release ghế, gửi email vé)
  • Real-time: WebSocket server + Redis Pub/Sub
  • Observability: Prometheus + Grafana dashboard, k6 load testing

🧠 7 Bài toán Kỹ thuật Trọng tâm

1. Double-booking race condition: PostgreSQL row locking + Redis Redlock distributed lock.
2. Ghế trống throughput cao: Redis cache giảm tải response time từ 200ms xuống 5ms.
3. Semantic Search: Hybrid search pgvector + Full-text search tsvector.
4. Idempotency Payment: Idempotency-Key lưu Redis chống double-charge khi lag.
5. Auto-release ghế: Redis TTL + BullMQ worker tự động nhả ghế sau 5 phút.
